# Phishing Email Analyzer

A Python-based tool for analyzing raw `.eml` files and identifying phishing indicators.

## Planned Features

- `.eml` parsing
- Email header analysis
- SPF, DKIM, and DMARC analysis
- Sender and Reply-To mismatch detection
- URL and attachment analysis
- Phishing risk indicators
- Explainable analysis reports
- Web interface
